# 観相堂（かんそうどう）

生年月日を入力すると、性格の違う4人の占い師があなたを占ってくれるWebアプリです。
サーバーは不要。ブラウザだけで動き、無料の **Gemini API** を呼び出して鑑定文を生成します。

- 🗡️ ズバッと先生（辛口・単刀直入）
- 🌙 やさしい癒し系（肯定重視・寄り添い）
- 💌 恋愛専門鑑定士
- 💼 仕事運鑑定士

## 使い方（自分のPCで試す）

1. このフォルダをそのままブラウザで開くか、簡易サーバーを立てて開きます。

   ```bash
   npx serve .
   # または
   python3 -m http.server 8000
   ```

2. [Google AI Studio](https://aistudio.google.com/apikey) で無料のGemini APIキーを発行します（クレジットカード不要、無料枠あり）。
3. アプリ内の「三、APIキーの設定」を開き、キーを貼り付けて保存します。
   - キーは**あなたのブラウザのlocalStorageにのみ**保存されます。どこにも送信されるサーバーは存在しません。
4. 占い師を選び、生年月日を入れて「見立てを申す」を押すだけです。

## GitHub Pagesで公開する

1. このリポジトリをGitHubにpushします。
2. リポジトリの Settings → Pages → Branch を `main` / `root` に設定します。
3. 数分後、`https://halumv3.github.io/-kansoudo/` で公開されます。

APIキーは各利用者が自分で発行して自分のブラウザに保存する仕組み（BYOK方式）なので、
あなたのキーを他人と共有する必要はありません。

## モデル名について

`app.js` の `GEMINI_MODEL` は `gemini-flash-latest`（常に最新のFlashモデルを指すエイリアス）を
使っています。Googleがモデルを入れ替えると挙動が変わることがあるので、うまく動かなければ
[モデル一覧](https://ai.google.dev/gemini-api/docs/models) で現行の無料枠モデル名を確認し、
書き換えてください。

## 占いのロジックについて

厳密な「算命学」（十大主星・十二大従星・天中殺など）は実装しておらず、
西洋占星術の星座と十二支をネタとしてAIに渡し、キャラクターの口調で自由に語らせる方式です。
本格的な算命学ロジックを実装したい場合は、干支暦（節入り日を考慮した干支変換）が必要になるため、
[lunar-javascript](https://github.com/6tail/lunar-javascript) のような暦計算ライブラリを
組み合わせるのがおすすめです。

## 今後の展望：手相・顔相占い（写真アップロード）について

「写真を撮って手相・顔相を占う」機能は魅力的ですが、**顔や手のひらの画像は生体に紐づく
センシティブな情報**なので、実装する場合は次の設計を強くおすすめします。

- **自前のサーバーに画像を保存しない。** 保存した瞬間、漏えい・不正アクセスのリスクを
  自分たちで背負うことになります。このアプリのようにサーバーレス構成のままにするのが安全です。
- ブラウザから直接Gemini（マルチモーダル対応）のようなAPIに画像を送り、**結果を受け取ったら
  画像はメモリ上で破棄する**（変数に持たない、IndexedDBやlocalStorageに入れない）。
- ただしその場合も、画像はGoogleなど第三者のAPIには一度送信されます。ここは「自分のサーバーには
  残らない」だけであって「どこにも送信されない」わけではないので、利用規約とプライバシーポリシーに
  必ず明記し、アップロード前に同意を取ってください。
- 可能なら、送信前にブラウザ側でEXIF情報（撮影場所・日時など）を削除する処理を挟むとより安全です。
- 未成年の利用が想定される場合は、写真アップロード系の機能自体を無効化することも検討してください。

まずはテキストベースの本アプリで公開し、需要と実装コストを見ながら段階的に写真機能を
足していく進め方が現実的だと思います。
